An entry for make.fun's [Dad Joke Showdown](https://make.fun/bounty/u-mfnakmal-dad-joke-showdown-1d2ce3e5) bounty ($5 in USDC).

## The entry

One dad joke, written to be told out loud — a clean pun, tight, with the
punchline at the end. A judge model reads the entries two at a time and picks
the one that earns the bigger groan.

## How it works

`main.py` (Python 3.13, no dependencies) writes exactly one dad joke to
`/output/entry.txt` — UTF-8 text, well under the 200-character gate.

Run it locally:

```sh
python3 main.py
```
